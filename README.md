# 百度网盘视频导航・使用说明（纯跳转版）

把网盘里多个目录的视频整理成一个**卡通风格**的网页：**点左侧分类 → 右侧显示该分类的视频卡片 → 点卡片跳到百度网盘官方页面播放**。

本版本**不需要任何服务器**：电脑可以关机，网页放到哪台设备上都能直接用（平板、手机、电脑都行），播放次数记在各设备自己的浏览器里。

## 在线访问（推荐，已部署好）

所有设备直接打开这个网址即可，**不需要拷贝任何文件**：

**https://741168607-ken.github.io/video-nav/**

- 电脑 / 平板 / 手机浏览器打开即用；
- 首次使用先在该浏览器登录一次 `https://pan.baidu.com`；
- 网盘里新增视频后，只需在电脑上更新 data.js 并推送到 GitHub（方法见文末"更新线上列表"），所有设备访问的网址自动更新。

## 文件夹里有什么

| 文件 | 作用 |
| ---- | ---- |
| `index.html` | 网页本体（卡通界面：分类导航 + 视频卡片 + 播放次数） |
| `apple-touch-icon.png` | 主屏幕图标（Super Simple Songs 风格） |
| `data.js` | 视频列表数据（由 `sync.py` 生成，**勿手改**） |
| `icons/` | 各分类的卡通图标（网页展示用） |
| `sync.py` | **只在电脑上**用来更新视频列表（`python sync.py`），不需要 `serve` |
| `config.json` | 你的百度网盘登录凭证（BDUSS）和要收录的目录，`sync.py` 用 |
| `cache.json` | 分享链接缓存（脚本自动维护，可忽略） |
| `index-本地代理版备份.html` | 旧版"本地代理播放"页面备份（需要电脑开服务才能用，一般用不上了） |
| `旧手机当服务器.md` | 备选方案：把旧手机当服务器来用（如果以后想回到"页面内直接播放"再参考） |

> 网页本身和视频数据都在设备本地或线上仓库，**播放视频时**才跳转到百度网盘官网页面（需要设备浏览器已登录百度账号，只需登录一次）。

## 工作原理（简单版）

- 网页 = **目录 + 播放次数**：纯静态文件，不需要任何服务；
- 点视频卡片 → 跳到 `pan.baidu.com` 的官方播放页播放（走百度自己的播放器）；
- 播放次数：每次点开视频自动 +1，存在**本设备浏览器**（localStorage）里，换设备各自计数。

## 电脑端准备（两种方式都需要，一次性）

### 第 1 步：电脑上安装 Python（如果还没装）

打开命令行（在文件夹地址栏输入 `cmd` 回车），执行 `python --version`。若提示找不到命令，到 https://www.python.org/downloads/ 下载安装，安装时务必勾选 **Add python.exe to PATH**。

### 第 2 步：获取 BDUSS（一次性，给 sync.py 用）

1. 用 Chrome / Edge 打开 https://pan.baidu.com 并登录你的账号；
2. 按 `F12` 打开开发者工具 → 顶部选择 **应用 / Application** → 左侧 **存储 → Cookie → https://pan.baidu.com**；
3. 找到 **BDUSS**，双击"值"列全选复制，粘贴到 `config.json` 的 `"bduss": ""` 里；
4. 在 `config.json` 的 `"categories"` 里确认要收录的网盘目录路径（格式见文件内注释，路径要和网盘里完全一致，含空格）。

### 第 3 步：生成视频列表

在文件夹打开命令行，执行：

```
python sync.py
```

看到"共收录 N 个视频"之类的提示即成功，这会更新 `data.js`。以后网盘里加了新视频，重跑这条命令即可。

### 第 4 步：把网页放到想用的设备上（离线方式）

> 如果使用上面的**在线网址**，这一步可以跳过，直接打开网址即可。

把以下四个东西一起复制到目标设备（电脑、平板、手机都可以）：

- `index.html`
- `apple-touch-icon.png`
- `data.js`
- `icons/` 文件夹

用浏览器直接打开 `index.html` 即可。**不需要联网跑服务，不需要电脑开机。**

> 建议：设备浏览器先登录一次 https://pan.baidu.com （点视频时就不会要求登录）。

## 日常使用

- **点左侧分类** → 右侧显示该分类的视频卡片；
- **点任意卡片** → 跳到百度网盘官方页面播放该视频，同时本设备"播放次数" +1；
- **播放次数**：卡片上显示"还没播放过 / 播放 N 次"，存在本设备浏览器里；
- **清零播放次数**：左侧栏底部"🧹 清零播放次数"按钮，点击确认后本设备所有次数归零（每台设备各自清零）。

## 常见问题

- **点视频后百度提示登录/空白**：先在这个浏览器里登录一次 https://pan.baidu.com 再试。
- **打开百度页面后视频没有自动播放、也没有全屏**：这是 **iPad 的系统限制**（iOS 禁止带声音的视频自动播放）和百度页面的跨站限制，任何外部网页都无法替百度播放器"点播放/点全屏"。请在百度播放器里点一下播放键，需要全屏时点播放器右下角的全屏按钮（或把平板横过来）。如果希望"打开即自动全屏播放"，只能用**百度网盘 App** 打开视频（App 默认全屏自动播放）。
- **点视频没有跳转**：部分浏览器对"打开新窗口"有限制，换成 Chrome / Edge / Safari 的普通模式；如果是网页被嵌在别的应用里打开，改成用浏览器打开。
- **视频列表不是最新的**：在电脑上重跑 `python sync.py`，把新的 `data.js` 复制到设备（或推送到 GitHub）。
- **播放次数换了设备不见了**：次数存在各设备自己的浏览器里，是设计如此（无服务器就无共享）。
- **卡片上的图为什么是分类图标**：百度网盘接口不提供视频封面帧，用分类卡通图标占位，这是接口限制。

## 安全提示

- `config.json` 里的 BDUSS 等同于你的登录凭证：**不要发给任何人，不要上传到网盘或云端，也不要提交到 GitHub 仓库**（本次部署的仓库里没有任何账号信息）；
- 本脚本只读取文件列表，不会修改或删除网盘中的任何文件；
- 视频播放跳转到百度官方页面，账号信息只由百度处理，不经过任何第三方。

## 更新线上列表（GitHub Pages）

在电脑上：

1. 运行 `python sync.py` 生成新的 `data.js`；
2. 把新的 `data.js` 复制到部署目录 `C:\Users\TUF\gh-deploy\video-nav\` 覆盖；
3. 在该目录打开命令行，依次执行：

```
git add data.js
git commit -m "更新视频列表"
git push
```

4. 等 1~2 分钟，刷新线上网址即可看到新视频。
